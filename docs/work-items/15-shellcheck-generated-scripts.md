# Shellcheck On Generated Scripts

## Goal

Add shellcheck validation as a `nix flake check` to catch shell bugs in the
Nix-generated wrapper and seed scripts before they reach users.

## Why

`mkWrappedCommand` and `mkSeedSecretsScript` in `lib/default.nix` produce
shell scripts at evaluation time. These scripts currently have no static
analysis pass — issues like unquoted variables, bad substitutions, or
non-portable constructs are only caught at runtime, and only on code paths
that happen to be exercised.

Shellcheck is a well-understood tool that flags exactly these classes of bugs.
Running it as a `nix flake check` on the generated wrapper scripts gives a
fast feedback loop with no runtime machinery.

## Scope

- add `pkgs.shellcheck` to `devShells.default`
- add one or more checks that extract representative wrapper/seed scripts and
  run shellcheck on them (can use the same fake-fnox pattern as
  `checks/wrapper-tests.nix`)
- fix any shellcheck findings discovered in the process
- document that new shell code added to `lib/default.nix` must pass shellcheck

## Non-Goals

- checking third-party shell scripts not generated by this flake
- enforcing strict POSIX sh (bash-specific constructs are fine where needed)

## Validation

- `nix flake check` runs shellcheck and fails on new violations
- `devShells.default` gives contributors `shellcheck` at their fingertips
